# スコアボード

複数の審査員がそれぞれのスマホ・PC から採点し、管理者が演出付きで順位を発表する Web ページです。
画面は GitHub Pages、データは Google スプレッドシート (Google Apps Script) に保存します。

- 公開ページ: https://ns-private.github.io/score-ranking/
- デモ (このブラウザ内だけで動く体験版、管理者パスワード `admin`): https://ns-private.github.io/score-ranking/?mock

## 使い方

| 役割 | 開く URL | できること |
|---|---|---|
| 審査員 | `https://ns-private.github.io/score-ranking/` | 自分の名前と PIN でログインし、参加者をタップして採点 |
| 管理者 | `https://ns-private.github.io/score-ranking/#admin` | パスワードでログインし、審査員・参加者・評価項目の登録 / 削除、採点状況の確認、結果発表 |

- 審査員は起動時・「更新」ボタン・得点保存のたびに、管理者が登録した最新の情報を読み込みます。
- 各評価項目の点数は「採点した審査員の平均」、順位はその合計で決まります (同点は同順位)。
- 審査員の画面には自分の得点しか表示されません。管理者画面の採点状況も「入力済みかどうか」だけで、得点は結果発表まで表示されません。
- PIN は管理者画面で「PIN を表示」にチェックしたときだけ見えます (画面共有対策)。
- PIN またはパスワードを続けて間違えると、10 分間ロックされます。

## 初回セットアップ (Google スプレッドシート)

1. Google ドライブで新しいスプレッドシートを作成します (名前は自由)。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. `コード.gs` の中身をすべて消し、このリポジトリの [`apps-script/Code.js`](apps-script/Code.js) の内容を貼り付けて保存します。
4. スプレッドシートの画面に戻って再読み込みすると、メニューに「スコアボード」が表示されます。
   1. 「スコアボード」→「初期設定 (シートを作成)」を実行します (初回は Google の承認画面が表示されます)。
   2. 「スコアボード」→「管理者パスワードを設定」でパスワードを決めます。
5. Apps Script の画面で「デプロイ」→「新しいデプロイ」を選び、次の設定でデプロイします。
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`) を、このリポジトリの [`config.js`](config.js) に設定して GitHub に反映します。

```js
window.SCOREBOARD_API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

### Code.js を更新したとき

Apps Script の「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」でデプロイし直してください (URL は変わりません)。

## データ (スプレッドシートのシート)

| シート | 内容 |
|---|---|
| 設定 | 大会名 |
| 審査員 | id / 名前 / PIN |
| 参加者 | id / 名前 |
| 評価項目 | id / 名前 / 満点 |
| 得点 | 審査員 id / 参加者 id / 評価項目 id / 点数 / 更新日時 |

スプレッドシートを直接編集することもできますが、通常は管理者画面から操作してください。
管理者画面で審査員・参加者・評価項目を削除して保存すると、関連する得点も削除されます。

## ファイル構成

- `index.html` / `style.css` / `app.js` — 画面
- `config.js` — Apps Script の URL
- `apps-script/Code.js` — Apps Script に貼り付けるサーバー側のコード
- `mock-gas.js` — `?mock` 付きで開いたときに使う動作確認用モック
