# スコアボード

競技者ごとに項目別の得点を入力し、演出付きで順位を発表する Web ページです。

公開ページ: https://ns-private.github.io/score-ranking/

## 機能

- 競技者の追加・削除・名前変更
- 評価項目(プレゼン力、コミュニケーション力など)の追加・削除・名前と満点の変更
- 得点表での得点入力と合計の自動計算
- 「結果発表」ボタンで演出付きの順位発表(4位以下 → 3位 → 2位 → 1位 → 表彰台)
  - 同点は同順位として同時に発表
  - 次へ進むのは「次へ」ボタン / Space / Enter / →、閉じるのは Esc
- 入力内容はブラウザ(localStorage)に自動保存
- JSON ファイルでの保存・読込

※ データは閲覧しているブラウザ内にのみ保存され、他の人とは共有されません。
